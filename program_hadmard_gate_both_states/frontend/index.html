Circuit Lab — User Guide

Welcome to CUDA-Q Circuit Lab — a visual quantum circuit builder that runs real simulations on your CPU or NVIDIA GPU using the CUDA-Q quantum computing framework.

①
Configure

Set the number of qubits (1–29) and measurement shots in the left sidebar.

②
Build a circuit

Click a gate in the palette then click any qubit row to place it. Drag gates to move them. Click a placed gate to remove it.

③
Run

Press ▶ Run circuit or hit Enter. Results appear in the right panel with a bar chart and bit breakdown.

④
Analyse

Read measurement counts, probabilities, the most likely output state, and live resource usage (CPU RAM / GPU VRAM).

Experiment 1 — Superposition with Hadamard

  1. Set Qubits to 1 using the + / − buttons.
  2. Set Shots to 1,000.
  3. Make sure qpp-cpu is selected as the target.
  4. Click the qubit row label q0 in the circuit board — it highlights blue.
  5. Click the H tile in the gate palette. An H gate appears on q0 column 0.
  6. Press Enter or click ▶ Run circuit.
  7. The results panel shows ~50% |0⟩ and ~50% |1⟩ — superposition confirmed.

Experiment 2 — Bell State (Entanglement)

  1. Set Qubits to 2.
  2. Click q0, then click H — places H on q0 at column 0.
  3. Click q1, then click CNOT — places CNOT target on q1 at column 0, with a control dot on q0.
  4. The control dot on q0 and the CNOT on q1 are connected by a vertical line — this is the entangling gate.
  5. Press Enter. Expect ~50% |00⟩ and ~50% |11⟩ — a Bell state.

Experiment 3 — Apply a Gate to Many Qubits at Once

  1. Set Qubits to 10 (or any number).
  2. Scroll down the left sidebar to the BULK APPLY panel.
  3. Select gate H, set From q = 0, To q = 9.
  4. Choose Same column from the Column dropdown.
  5. Click ⚡ Apply to all — all 10 qubits get an H gate at column 0 instantly.
  6. Press Enter to run. You will see a uniform distribution across all 2¹⁰ = 1024 basis states.

Experiment 4 — Sticky Gate (Fast Placement)

  1. Click any gate in the palette — it glows cyan, meaning it is selected.
  2. Now click any empty cell on the circuit board — the gate is placed there immediately.
  3. Keep clicking different cells to place the same gate repeatedly without re-selecting.
  4. Click the same palette tile again (or press Esc) to deselect it.

Experiment 5 — Span a Gate Across Qubits

  1. Place a gate (e.g. H) on q0.
  2. Hover over the gate — a small ▼ appears in its bottom-right corner.
  3. Click and hold the ▼, then drag downward across qubit rows.
  4. A gold label shows the live span (e.g. H → q0 – q7, 8 qubits) and rows highlight.
  5. Release the mouse — the gate is copied to every qubit in the covered range at the same column.

Experiment 6 — CPU vs GPU Comparison

  1. Build any circuit (a Bell state works well).
  2. Click ▶▶ Compare targets in the left sidebar.
  3. The app runs the same circuit on both qpp-cpu and nvidia and shows execution times side by side.
  4. If no GPU is available, the nvidia result shows "Unavailable" — CPU result still works.

Good to Know

🎯

Initial states — each qubit starts in |0⟩ by default. Click the state button (e.g. q0 |0⟩) to cycle through |0⟩, |1⟩, |+⟩, |−⟩.

📊

Shots — more shots give smoother probability estimates. Use 1,000 for quick tests, 10,000 for precise distributions.

⚡

GPU target — select nvidia for hardware-accelerated simulation. Requires an NVIDIA GPU with matching CUDA drivers. Falls back to a local preview if unavailable.

🔢

Bit ordering — results follow q0-left convention: the leftmost bit is q0, the rightmost is q(n−1). E.g. |01⟩ means q0=0, q1=1.

↩

Undo everything — every gate placement, removal, state change, and bulk apply is undoable with Ctrl+Z. Up to 60 steps are kept.

📐

Circuit depth — shown in the circuit header (e.g. 3 qubits / 2 depth). Depth is the number of sequential gate layers your circuit uses.

🖥

Resource usage — after each run the right panel shows CPU RAM and GPU VRAM usage so you can monitor how your circuit scales.

🔍

State formula — after running, the right panel shows the exact quantum state vector equation (disabled above 20 qubits to avoid browser slowdown).
